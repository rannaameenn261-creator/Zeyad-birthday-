# Zeyad's 25th Birthday Website ❤️

A romantic + elegant single-page birthday website made for Zeyad.

## GitHub Pages
1. Upload everything in this folder to a GitHub repository.
2. Go to **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/root`, then Save.
4. Your site will appear at your GitHub Pages address.

## Add the song 🎵
The site is already wired for a local file named:

`assets/song.mp3`

Put your legally obtained copy of **"Song.MP3"** in the `assets` folder with exactly that filename.

The website does not include the copyrighted audio file itself.
